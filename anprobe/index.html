KI-Setup

Die Anprobe nutzt Googles Bild-KI Gemini (Nano Banana Pro). Für die Demo kann direkt ein API-Key hinterlegt werden (bleibt nur in diesem Browser, localStorage). Für den Live-Betrieb im Ordertool wird stattdessen die Proxy-URL genutzt, damit kein Key im Browser liegt – siehe README.
Hinweis: Die Anprobe ist eine KI-Visualisierung und kann von Passform und Farbe des realen Produkts abweichen. Sie ersetzt keine Größenberatung.
Datenschutz: Dein Foto wird ausschließlich zur Erstellung der Anprobe an die Google-Gemini-API übertragen und von dieser Seite nicht gespeichert.
